# Pixel portrait set

These 28 original 256×256 portrait files are the existing square portrait fallback family already referenced in `src/art.mjs`, copied locally for consistent framing and reliable loading. No full-body or skin art is mixed into Pixel. Files are unmodified.

Source: https://github.com/moeneri/astrbot_plugin_apexrankwatch/tree/main/assets/legends

Character artwork belongs to Electronic Arts / Respawn Entertainment. The site is an independent fan project. Filename `mad-maggie.png` is the source file `mad_maggie.png`; all other filenames use the Legend slug.
